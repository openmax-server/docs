# Описание основ Websocket

Шлюз вебсокета является 1 из транспортов протокола MAX (всего их 2) и используется только веб версией клиента (web.max.ru). ~~Официальный сервер располагается по адресу `wss://ws-api.oneme.ru/websocket`.~~ По состоянию на июль 2026, адрес сервера изменён на `wss://api.oneme.ru/websocket`.

# Структура пакетов

~~Вот пример типичного пакета, который может поступить в вебсокет:~~

По состоянию на июль 2026, пакеты стали бинарными, данные кодируются в стандарте Messagepack (так же, как и в сокете).

- ver — версия протокола
- cmd — тип команды
- seq — порядковый номер пакета
- opcode — номер команды
- payload — данные пакета

Где cmd:
- 0 — всегда ставит клиент, и иногда сервер в некоторых командах
- 1 — успех выполнения операции (отправляет всегда сервер)
- 2 — не используется
- 3 — ошибка при выполнении команды (отправляет всегда сервер)
